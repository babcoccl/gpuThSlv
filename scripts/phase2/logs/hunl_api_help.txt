NAME
    gpu_cfr.games.hunl_river - HUNL river endgame GameSpec builder.

DESCRIPTION
    Models a single-street river subgame as a chance-rooted EFG: the root chance
    node deals one (hand0, hand1) combination from the two players' ranges
    (uniform over non-conflicting pairs), followed by a one-street betting tree
    (check / bet / fold / call, no raises — the structure used by
    project_1_1/tree.py). Payoffs are in the same chip units as ``pot``/``stack``.
    
    Payoff convention (player 0 view): the pot before river action is split
    half/half as sunk contributions, so winning a showdown or a fold is worth
    ``pot/2`` plus whatever additional chips the opponent put in.

==================== gpu_cfr.games.hunl_turn ====================
Python Library Documentation: module gpu_cfr.games.hunl_turn in gpu_cfr.games

NAME
    gpu_cfr.games.hunl_turn - HUNL turn endgame GameSpec builder (Libratus-style two-street subgame).

DESCRIPTION
    Extends the river endgame of :mod:`hunl_river` by one street: the root chance
    node deals one (hand0, hand1) combination, a turn betting street follows the
    same no-raise grammar, and every betting line that does not end in a fold
    reaches a second chance layer that deals one of the remaining river cards
    (uniform over the 52 - 4 - 4 = 44 cards unseen by either player), followed by
    a river betting street whose bet sizes are fractions of the grown pot capped
    by the remaining stack.
    
    Payoff convention (player 0 view) matches hunl_river: the pre-turn pot is
    split half/half as sunk contributions, so a fold forfeits the folder's sunk
    chips (half-pot plus their turn contribution on the river street) and a
    showdown is worth the winner's sunk-plus-matched total.
